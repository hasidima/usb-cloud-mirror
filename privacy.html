USB cloud mirror · Privacy

Privacy statement

USB cloud mirror is used solely by its owner for personal file mirroring.

Data accessed and purpose

The utility reads Google Drive file names, folder structure, identifiers, modification dates and document content needed to create and update copies on a local encrypted USB disk.

Storage

Exported document contents are stored on the encrypted USB disk. Connection credentials, transfer logs and file-list information are stored locally on the owner's computer. The disk encryption password is stored in the local Mac Keychain for automatic unlocking; it is not placed on this website or in the copying scripts.

Sharing

The utility does not upload copied documents or credentials to this website, advertising services or analytics services. It connects to Google to read and export the authorised files.

Retention and control

Copies are updated to reflect the source files. The owner controls and can delete the local copies, local settings and credentials. Google access can be revoked in the owner's Google Account connection settings.

This website

This website has no login or file upload features. GitHub hosts these information pages and may process ordinary website request information under the GitHub privacy statement.

Google API policy

The utility's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
